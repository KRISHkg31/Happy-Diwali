# Happy-Diwali 🪔✨

An interactive, festive Diwali celebration web card crafted with modern web animations, sound synthesis, and interactive surprises.

## ✨ Features
- 🪔 **Interactive Gate**: Drag the matchstick to light the central Diya and illuminate the dark room.
- 🎆 **Physics Fireworks Canvas**: Real-time particle fireworks with ring and heart explosions.
- 💬 **Celebration Chat**: Simulated personal messages with interactive reply chips.
- 🪔 **The Five Sacred Diyas**: Light 5 wish diyas in a responsive bento grid, each triggering ascending musical chimes.
- 🏮 **Sky Wish Lanterns**: Type and release warm glowing lanterns into the night sky.
- 🎇 **Phuljhadi Sparkler Pad**: Smokeless touch/cursor-driven canvas sparkler with multi-colored sparks.
- 🎟️ **Golden Scratch Card**: Metallic brushed gold scratch foil revealing a special voucher.
- 🔊 **Web Audio Synthesizer**: Built-in sound effects (chimes, spark crackles, firework booms) without external audio files.
